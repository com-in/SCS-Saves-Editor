# 2026-10-17

## Mod 页「选择目录不填充」根因与修复

- 用户反馈：Mod 页点「选择…」后目录不填充、无任何反应。
- 排查过程：先用 mock 对话框 + 临时游戏目录复现，`_mods_pick_game_dir` 逻辑全部正常
  （选根目录 / `*_Data` / `*_Data\Managed` 都能归位填充）；再测真实按钮链路时发现
  `isEnabled() == False`。
- 根因：`_document.py` 的 `_refresh_document_state()` 有「未打开存档就禁用页面」的门控，
  白名单只有 `home / memory / map3d`，Mod 页（key `mods`）不在其中 → 没开存档时整页
  按钮禁用，点击无响应（用户看到的「不填充」）。
- 修复：白名单加 `'mods'`（Mod 页只操作游戏目录的 BepInEx，与存档无关）。
- 固化回归测试 `tests.test_editor.EditorTests.test_mods_page_is_usable_without_an_open_save`：
  未开存档时 tab_mods 及「选择…」「自动查找」按钮可用，且 tab_basic 仍保持禁用；
  已验证撤销修复后该测试失败（能抓住回归）。
- 全量回归 97 项通过。同步更新 README（注明无需开存档）、CHANGELOG v1.4.0。
- 注意：Qt 的 `isEnabled()` 会把父级禁用算进去，排查类似「按钮点了没反应」问题时应
  检查祖先链而不只是按钮本身；用 findChildren 找按钮时要确认页面归属，否则会误匹配
  其他页同名按钮。
