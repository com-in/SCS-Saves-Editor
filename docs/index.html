FEATURES

从数据到布局，都能照顾到。

01 / 存档编辑

常用数据集中管理

修改货币、等级、经验、电力等基础数据，管理工人能力和状态，查看物品、升级及其他存档字段。

02 / 可视化地图

直接调整园区设施

读取游戏场景，按楼层查看设施位置；放置物品、拖动移动、调整朝向，完成后保存到存档。

03 / Mod 管理

多种方式导入插件

安装 BepInEx 加载器，通过本地 ZIP / DLL、文件直链或在线清单安装 Mod，并管理启用、禁用和卸载。

保存前自动备份到存档同目录的 ES3_Backups 文件夹。地图是碰撞体提取的简化布局；编辑后需点击「保存存档」才会写入。

GET STARTED

开始使用，只需几步。

  1. 01

    下载并启动

    前往项目 Releases 下载 Windows 程序。首次使用时，先保留一份自己的原始存档副本。

  2. 02

    选择工作内容

    编辑数据时打开 .es3 存档；使用地图时选择游戏目录。安装 Mod 可直接打开对应页面，无需先加载存档。

  3. 03

    确认并应用

    存档编辑完成后点击保存。安装 Mod 前先退出游戏，选择游戏目录并检查 BepInEx 加载器状态。

MOD DIRECTORY

把在线清单接入修改器。

复制下方地址，粘贴到「安装 Mod → 在线 Mod 清单」，点击「刷新」，再选择需要的 Mod 安装。
