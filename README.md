# 诈骗园区模拟器 - ES3 存档修改器

基于 Python + PySide6 开发的《诈骗园区模拟器》存档修改工具。可安全读取、编辑并写回 Unity **ES3** 格式存档（JSON，顶层 key 为 `"__type"` / `"value"` 包装），内置自动备份，防止误改损坏存档。

## ✨ 功能特性

- **安全读写**：支持打开 / 保存 `.es3` 存档，写回时使用临时文件 + 原子替换，避免数据损坏。
- **自动备份**：每次保存前自动把原档备份到存档同目录下的 `ES3_Backups/` 文件夹。
- **基础数据**：货币、等级、经验、天数、电力、店名、呼叫数据、难度等一键编辑。
- **工人管理**：查看 / 修改工资金钱、能力值、状态，支持搜索、批量加满、重置状态。
- **加密货币 / 物品 / 放置物品 / 升级 / 其他**：表格或原始 JSON 编辑。
- **游戏地图**：读取游戏 `level1` 场景中的地板和墙体，按存档区域或全图查看；使用左右方向按钮切换楼层，选择物品点击地面放置，拖动已有标记调整位置，Q/E 调整方向。修改后仍需保存存档。
- **安装 Mod**：检测游戏目录是否已装 BepInEx 并可一键安装官方发行包；支持本地 zip / dll 导入、HTTP/HTTPS 文件直链安装、在线清单安装，以及已装 Mod 的启用、禁用与卸载。
- **界面**：左右布局 + 可折叠侧边栏、亮色 / 暗色主题切换、默认全屏、标题栏显示当前文件名。
- **检查更新**：启动后后台检查 GitHub 最新正式版，也可从“帮助 → 检查更新”手动检查，并可关闭启动自动检查。Windows EXE 版支持国内加速或 GitHub 下载，校验文件后询问是否退出更新；确认后释放 BAT，等待旧进程退出、备份旧 EXE、替换并重启。源码运行仍通过浏览器下载。

## 🚀 本地运行

```bash
# 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 启动
python main.py
```

## 📦 打包发布

程序已配置 **GitHub Actions**（`.github/workflows/build.yml`），会在推送到 `v*` 标签时自动用 PyInstaller 打包（内嵌 `icon.ico`），打包结果上传为 **Artifact** 并发布 **GitHub Release**。

```bash
# 手动本地打包
pyinstaller --noconfirm --clean --onefile --windowed `
  --name "SCS" `
  --icon "icon.ico" `
  --add-data "icon.ico;." `
  --add-data "docs/mods_index.json;docs" `
  --hidden-import unity_scene_loader `
  --collect-all UnityPy `
  "main.py"
```

> 发布新版本：推一个新标签（如 `v1.1.0`）即可自动触发构建与发布。

## 📁 项目结构

Mod 链接清单位于 `docs/mods_index.json`，字段说明及填写示例见 [docs/README.md](docs/README.md)。

```
main.py                     # 程序入口（PySide6 界面 + 存档处理）
unity_scene_loader.py       # 从 Unity 场景提取地板、墙体与区域定位信息
icon.ico                    # 程序 / exe 图标
requirements.txt            # 依赖
.github/workflows/build.yml # 自动打包并发布 Release
ES3_Backups/                # 保存时自动生成的备份目录
```

## ⚠️ 使用提示

- 修改后请点击顶部的【保存存档】才会写入文件。
- 地图页首次打开会解析游戏数据，随后使用本地缓存；无法自动定位游戏时，在地图页的【游戏目录】中选择安装目录或 `*_Data` 目录。
- 地图为游戏碰撞体提取的简化布局；放置物品读取各自预制体的实体 BoxCollider，保留子节点偏移、旋转、缩放和存档完整四元数，并非原版模型/贴图。悬停或选中显示名称、角度与碰撞体长宽；无法读取的物品标注“估算尺寸”。中键拖动平移地图，左键拖动物品移动、拖动空白旋转视角，滚轮缩放。墙体以低墙剖面展示，方便查看室内。
- 默认俯视方向为游戏世界坐标 `+Z` 向上、`+X` 向右；右上角方向标随视角旋转。白色箭头表示物品根节点的局部 `+Z` 方向，与物品长边不一定同向；旋转按游戏的世界 Y 轴方式叠加，保留原有倾斜。首次加载物品尺寸后会缓存，放置预览与已放置物品使用相同几何。
- 地图新增列表核对当前主场景的商店、市长兑换清单和存档物品注册表，只提供可购买或兑换且支持地面放置的设施；下拉框仅显示名称与等级，物品 ID 保留在内部用于准确保存。两类清单均未收录的资源不提供新增，原存档中的旧物品仍保留显示和编辑。无法核实清单时禁用新增，不影响地图查看。墙面物品暂不支持贴墙放置。新建货架保留对应货架类型，笼子使用空 NPC 列表。连续放置、移动和旋转保持当前取景；点击“刷新坐标”或切换视图范围可重新取景。目前只校验点击是否落在地面，尚未复现游戏的完整碰撞与室内/室外限制，请避免重叠放置。
- 物品名称按游戏的 `tier` 显示等级（例如床 Lv 2），不与玩家解锁等级混淆。未在商店上架不等于完全未使用，也可能来自市长兑换、场景专用或旧版本内容；不会据此删除存档记录。
- 退出放置模式后，选中地图上的已放置物品，点击“删除所选”或按 Delete 删除；同时解除工人的对应床位/工作台绑定，保存后写入文件。含 NPC 的笼子需先在游戏中移出 NPC，避免删除其唯一存档数据。
- 涉及结构复杂的数据（物品 / 放置物品 / 其他）以原始 JSON 形式提供，仅在你了解结构时修改。
- Mod 页只读写游戏目录下的 `BepInEx` 文件夹，不触碰存档文件；安装或卸载前请退出游戏，第三方 Mod 请自行确认来源可信。该页与存档无关，**不需要先打开存档即可使用**。首次使用点 Mod 页的【自动查找】，程序会扫描 Steam 库、Epic 目录和正在运行的游戏进程来定位安装目录；也可以点【选择…】手动指定，选中 `*_Data` 或它的子目录会自动向上归位到安装根目录。
- Mod 页的【文件直链】仅接受可直接下载的 HTTP/HTTPS `.zip` 或 `.dll` 地址，支持 URL 查询参数；网页展示页地址不会被当作安装包。
- 每次保存前会自动备份，若改坏可用 `ES3_Backups/` 里的备份还原。
